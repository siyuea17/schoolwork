##### 4、基于 URLLIB2 库的代码实现离线下载

新建文件夹创建 python 文件，粘贴代码

```python
from urllib2 import *
f = urlopen("http://host.docker.internal:8080")
g=f.read()
print g
outfile = open("output.txt","w")
outfile.write(g)
outfile.close()
```

##### 7、使用 Wireshark 进行抓包

```python
#使用容器内的基于SOCKET的离线浏览器.py

from socket import *

HOST = '172.27.94.102'
PORT = 8080
ADDR = (HOST, PORT)

data = 'GET / HTTP/1.1\r\nAccept-Encoding: identity\r\nHost: 172.27.94.102:8080\r\nConnection: close\r\nUser-Agent: Python-urllib/2.7\r\n\r\n'

tcpCliSock = socket(AF_INET, SOCK_STREAM)
tcpCliSock.connect(ADDR)
tcpCliSock.sendall(data)

response = ''
while True:
    datanew = tcpCliSock.recv(1024)
    if not datanew:
        break
    response += datanew

print response
tcpCliSock.close()

```

使用容器内的基于SOCKET的离线浏览器访问宿主机的localhost:8080，并使用wireshark进行抓包，在剔除掉容器内部 lo 接口的流量后的结果如下：

![image-20260911202652557](C:\Users\siyuea\AppData\Roaming\Typora\typora-user-images\image-20260911202652557.png)

|       客户端的发送内容        | 含义                                                       |
| :---------------------------: | ---------------------------------------------------------- |
|        GET / HTTP/1.1         | 告诉服务器要进行下载操作                                   |
|                               | 下载内容为根目录（/）下的东西，也就是首页                  |
|                               | 使用的协议版本为HTTP/1.1                                   |
|   Accept-Encoding: identity   | Python 2.7 urllib 的默认行为，表示能够接受未压缩的数据     |
|   Host: 172.27.94.102:8080    | 告诉服务器要访问是 IP 为 172.27.94.102，端口为 8080 的网站 |
|       Connection: close       | 不保持长连接                                               |
| User-Agent: Python-urllib/2.7 | 告诉服务器自己的浏览器（一个 Python 2.7 写的程序）         |

|            服务器发送的内容            | 含义                                                         |
| :------------------------------------: | :----------------------------------------------------------- |
|            HTTP/1.1 200 OK             | 告诉客户端收到了请求，返回状态码200，表示一切正常            |
|         Cache-Control: private         | 缓存策略。告诉浏览器或者客户端：这是私人页面，不允许与其他用户共享 |
| Content-Type: text/html; charset=utf-8 | 正文格式为 text/html 也就是网页，编码格式为 utf-8            |
|       Server: Microsoft-IIS/10.0       | 告诉客户端：服务器是微软的 IIS 10.0 服务器                   |
|        X-AspNetMvc-Version: 5.2        | 这是 IIS 服务器特有的头部。                                  |
|      X-AspNet-Version: 4.0.30319       | 同上                                                         |
|         X-Powered-By: ASP.NET          | 同上                                                         |
|  Date: Fri, 11 Sep 2026 11:55:20 GMT   | 服务器响应时长                                               |
|           Connection: close            | 服务器同意在发完正文之后关闭连接                             |
|          Content-Length: 3714          | 服务器告诉客户端正文大小为： 3714 字节                       |
|      <!DOCTYPE html> ... </html>       | 这是网页 HTML 源代码，请求下载的内容                         |
