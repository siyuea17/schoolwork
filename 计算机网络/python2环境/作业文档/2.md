##### 2、IIS的启动

按键盘上的 Win + R 键，打开“运行”窗口。输入 optionalfeatures ，点击“确定”。

在弹出的“ Windows 功能”窗口里，找到并展开 “ Internet Information Services ”。

展开 “ Web 管理工具”，勾选 “ IIS 管理控制台”。

展开 “万维网服务” -> “应用程序开发功能”，勾选：

​	ASP.NET 4.8（选项目对应的版本）

​	ISAPI 扩展

​	ISAPI 筛选器默认文档（在“常见 HTTP 功能”里，最好也勾上）

![image-20260911201511935](C:\Users\siyuea\AppData\Roaming\Typora\typora-user-images\image-20260911201511935.png)

点击“确定”，回到桌面，再按 Win + R ，输入 inetmgr ，回车打开 IIS 管理器。
