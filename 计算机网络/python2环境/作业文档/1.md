##### 1、搭建一个网站

在 Visual Studio Installer 里勾选 ASP.NET 和 Web 开发、.NET Framework 项目和项模板。

![image-20260911201157393](C:\Users\siyuea\AppData\Roaming\Typora\typora-user-images\image-20260911201157393.png)

创建一个 ASP.NET Web 应用程序 (.NET Framework)项目。

![image-20260911201249044](C:\Users\siyuea\AppData\Roaming\Typora\typora-user-images\image-20260911201249044.png)

按F5即可在浏览器运行默认网页。可以在Views文件夹里对网页进行修改，默认有三个页面：About.cshtml、Contact.cshtml、Index.cshtml。

![image-20260911201342047](C:\Users\siyuea\AppData\Roaming\Typora\typora-user-images\image-20260911201342047.png)

右键项目名，点击“发布”，选择发布到文件夹，其默认路径为项目目录下\bin\app.publish文件夹下。

![image-20260911201308651](C:\Users\siyuea\AppData\Roaming\Typora\typora-user-images\image-20260911201308651.png)
