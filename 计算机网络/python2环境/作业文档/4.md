##### 4、基于 URLLIB2 库的代码实现离线下载

新建文件夹创建 python 文件，粘贴代码

```python
from urllib2 import *
f = urlopen("http://host.docker.internal:8080")
g=f.read()
print g
outfile = open("output.txt","w")
outfile.write(g)
outfile.close()
```

地址栏由于我使用了 docker ，宿主机的 http://loaclhost:8080 变为 http://host.docker.internal:8080 。

保证网站在运行的同时，运行这个 python 程序，会在控制台输出Index.cshtml 里的源码，并在同级目录保存为 output.txt 。
